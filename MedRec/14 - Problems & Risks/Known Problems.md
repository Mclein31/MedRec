## 📝 Problem Logging Template

When a concrete defect, broken integration, or operational failure is discovered, record it using the following format:

```markdown
### PRB-XXX: [Concise Problem Title]
- **Severity**: `[Critical | High | Medium | Low]`
- **Discovered Date**: `[YYYY-MM-DD]`
- **Area / Module**: `[e.g., Auth / OCR Pipeline / SQLite Storage]`
- **Observed Behavior**: `[Detailed description of what is actually happening]`
- **Expected Behavior**: `[What should have occurred instead]`
- **Root Cause**: `[Explanation if identified, or 'Under Investigation']`
- **Workaround / Resolution**: `[Temporary mitigation or permanent fix plan]`
- **Related Notes**: [[Open Questions]], [[Technical Debt]]
```
