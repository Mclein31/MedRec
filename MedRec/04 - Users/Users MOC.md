# Users MOC

Hub for the **Users** section of the MedRec vault. Every note in this section is linked below.

---

## Notes in this section

- [[Clinics]] — Clinics encompass outpatient facilities, primary care practices, specialized private offices, and urgent care centers.
- [[Doctors]] — Doctors represent a critical secondary user and key external stakeholder for MedRec.
- [[Healthcare Administrators]] — Healthcare administrators, including Health Information Management (HIM) personnel, medical records officers, privacy officers, and clinic front-desk manager…
- [[Hospitals]] — Hospitals represent major institutional stakeholders within the healthcare ecosystem.
- [[Patients]] — Patients represent the primary user group and core focus of MedRec.
- [[User Journey]] — This document provides the foundational framework and empty template for mapping the end-to-end patient experience in MedRec.
- [[User Needs]] — This note captures the baseline user needs identified during early problem framing for Patients.
- [[User Pain Points]] — This note details the core pain points and friction areas identified during initial problem exploration.
- [[User Personas]] — To prevent designing for hypothetical or imaginary users, personas in MedRec will not be invented from fiction.
- [[User Stories]] — This document defines the user story format and maintains the initial backlog of draft user stories for MedRec.
